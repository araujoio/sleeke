# Sleeke

Sleeke é uma ferramenta para criação de projetos web com suporte à
internacionalização (i18n).

O objetivo do projeto é facilitar a criação de aplicações que precisam
trabalhar com diferentes idiomas, utilizando Next.js e ferramentas de
internacionalização.

## Tecnologias

- Next.js
- React
- TypeScript
- next-intl
- npm
