# Code of Conduct

Open source projects are living, collaborative spaces. Contributions in the form of issues, discussions, and pull requests are welcomed and encouraged. By participating in the Sleeke community, you agree to follow this Code of Conduct.

## The Code

We foster a respectful, harassment-free, and professional community. As members of this community, we work to:

- Be respectful and considerate, even in technical disagreements.
- Give and receive feedback constructively.
- Act professionally in all project spaces.

We will not tolerate:

- Harassment, personal attacks, or insults.
- Discriminatory or derogatory language.
- Trolling or deliberately disruptive behavior.
- Publishing someone else's private information without consent.

## Scope

This Code of Conduct applies to all Sleeke spaces, including GitHub Issues, Pull Requests, Discussions, and any other official project spaces.

### Reporting

If you witness or experience unacceptable behavior, please contact the Sleeke maintainers privately through their GitHub profile. Please avoid using public GitHub Issues for sensitive reports.

### Enforcement

Maintainers may take reasonable action when necessary to address violations of this Code of Conduct.
